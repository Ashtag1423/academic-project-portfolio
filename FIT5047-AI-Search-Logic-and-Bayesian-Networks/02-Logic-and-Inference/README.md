# Logic, Knowledge Representation and Inference

A summary of the submitted written assignment (no standalone implementation was supplied).

## Propositional logic

- Evaluate satisfiability and validity with truth assignments.
- Convert logical formulas to conjunctive normal form (CNF).
- Identify Horn and non-Horn clauses.

## Rule-based inference

- Represent statements as implication rules.
- Derive a goal (`S`, sick) from initial facts (`F`, fever; `E`, exhausted) using forward chaining.
- Recover the same goal by backward chaining over required subgoals.

## First-order logic

- Standardize variables, eliminate implications and Skolemize quantified formulas.
- Apply unification and resolution toward a contradiction with the negated goal.
