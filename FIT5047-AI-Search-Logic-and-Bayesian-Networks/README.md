# AI Search, Logic and Bayesian Networks (FIT5047)

A portfolio collection of university projects exploring heuristic search, adversarial decision-making, formal logic and probabilistic graphical models.

| Project | Focus |
| --- | --- |
| [Pacman Search](01-Pacman-Search/) | A* heuristics, multi-goal search, alpha-beta pruning, iterative deepening |
| [Logic and Inference](02-Logic-and-Inference/) | Propositional logic, CNF, Horn clauses, forward/backward chaining and resolution |
| [Bayesian Networks](03-Bayesian-Networks/) | Netica Bayesian network and influence/decision model for fraud detection |

**Notes:** Selected student-authored code is shown for portfolio review. Pacman agent files depend on the original course framework and are not standalone. Large datasets and full assessment PDFs are not included. Descriptions are based on the submitted project files and reports; no new benchmark results are claimed.
