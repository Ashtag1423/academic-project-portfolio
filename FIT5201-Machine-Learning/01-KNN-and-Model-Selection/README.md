# KNN Regression and Model Selection

Custom weighted KNN regression with Minkowski distance, blocked cross-validation with a gap to mitigate leakage, and nested cross-validation for model selection.

**Source:** FIT5201 university assignment notebook (portfolio version).

## Files

- `knn_model_selection.ipynb` — implementation, explanations and experiments.

## Data and reproducibility

scikit-learn Diabetes dataset included via scikit-learn; no additional dataset file needed.

Notebook code is preserved, but execution outputs and personal student ID have been removed. **Results have not been independently rerun or verified** for this portfolio package. Install the libraries listed in the repository `requirements.txt` before execution.
