# FIT5201 — Machine Learning Projects

Six selected notebook projects from two university assignments, organised for code review. The notebooks demonstrate supervised learning, model selection, probabilistic models, clustering, neural networks, and representation learning.

| Project | Focus |
| --- | --- |
| [01 — KNN and Model Selection](01-KNN-and-Model-Selection/) | Weighted KNN, blocked and nested cross-validation |
| [02 — Ridge Regression](02-Ridge-Regression/) | Gradient-based optimisation and regularisation |
| [03 — Generative vs Discriminative Models](03-Generative-vs-Discriminative-Models/) | Logistic regression, naive Bayes, Gaussian classifiers |
| [04 — EM Document Clustering](04-EM-Document-Clustering/) | Bag-of-words, mixture models, expectation-maximization |
| [05 — Perceptron vs Neural Networks](05-Perceptron-vs-Neural-Networks/) | Regularised perceptron, neural networks, hyperparameter tuning |
| [06 — Autoencoder Self-Taught Learning](06-Autoencoder-Self-Taught-Learning/) | Unsupervised feature learning and downstream classification |

## Technology

Python, NumPy, pandas, Matplotlib, scikit-learn and Jupyter Notebook.

## Reproduction notes

- Assignment 1 uses built-in or generated data.
- Assignment 2 references **`Dataset_S2_2025/`**, which is **not present** in the supplied archives. The original course dataset must be obtained separately before executing its notebooks.
- Cell outputs, embedded diagrams and student IDs were removed to make the code suitable for public review; this package does not claim independently reproduced results.
- Consult each project README for dataset names and context.

The content is selected student work, **not a standalone production software library**. Public sharing is subject to any applicable university course policies.
