# Autoencoder Representations and Self-Taught Learning

Trains autoencoders with different hidden layer sizes and compares downstream classifiers using input features versus augmented learned representations.

**Source:** FIT5201 university assignment notebook (portfolio version).

## Files

- `autoencoder_self_taught.ipynb` — implementation, explanations and experiments.

## Data and reproducibility

Requires `Dataset_S2_2025/Task2C_labeled.csv`, `Task2C_unlabeled.csv`, and `Task2C_test.csv` (not included).

Notebook code is preserved, but execution outputs and personal student ID have been removed. **Results have not been independently rerun or verified** for this portfolio package. Install the libraries listed in the repository `requirements.txt` before execution.
