# Document Clustering with Expectation-Maximization

Bag-of-words document clustering with an EM-based mixture model, multiple initialisations, PCA-based analysis and visualisation.

**Source:** FIT5201 university assignment notebook (portfolio version).

## Files

- `em_document_clustering.ipynb` — implementation, explanations and experiments.
