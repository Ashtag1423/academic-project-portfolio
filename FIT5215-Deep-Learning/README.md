## Technologies

Python, PyTorch, torchvision, NumPy, scikit-learn, recurrent networks (RNN, LSTM, GRU), attention, transformers, BERT, and pretrained word embeddings.

## Highlight

The Transformer notebook reports **94.5% test accuracy** in its best BERT prefix-tuning experiment on a six-class question classification task. This is the reported assignment result, not a freshly verified benchmark.

## Reproducing the work

Notebooks are shown for technical review. Execution outputs, personally identifying student details, original rendered HTML, large model checkpoints and datasets were excluded to keep the public portfolio lightweight. Some notebooks contain assignment-specific instructions and local paths; install dependencies, supply datasets, and adapt paths before running. No claim of out-of-the-box reproducibility is made.

These are excerpts of university coursework, not independent deployed products.
