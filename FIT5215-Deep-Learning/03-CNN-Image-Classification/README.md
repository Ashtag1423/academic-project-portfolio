# CNN Image Classification and Robustness

**Source:** FIT5215 Assignment 1, Part 3 (2025).

Builds convolutional blocks and CNN architectures, explores residual/skip connections and learning rates, Mixup and CutMix augmentation, one-versus-all loss, projected-gradient-descent (PGD) adversarial attacks, and adversarial training.

**File:** `cnn_image_classification.ipynb`

**Reproduction note:** Original code uses a local Windows dataset path, which must be adapted. Datasets and model checkpoints are not bundled.
