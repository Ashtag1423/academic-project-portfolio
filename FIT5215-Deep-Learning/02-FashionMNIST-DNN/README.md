# FashionMNIST — Feed-forward Neural Networks

**Source:** FIT5215 Assignment 1, Part 2 (2025).

Experiments with FashionMNIST classification using PyTorch feed-forward networks, activation and hidden-layer grid search, entropy-regularized loss, and sharpness-aware minimization (SAM).

**File:** `fashion_mnist_dnn.ipynb`

**Dataset:** FashionMNIST, downloaded through `torchvision` when executed. The notebook needs its Python dependencies and access to download data.
