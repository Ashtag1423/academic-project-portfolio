# CNN Image Classification

**Topics:** convolutional networks, augmentation, normalization, dropout, residual connections and model comparison.

Developed and compared CNN architectures on a 200-class Tiny ImageNet subset. Experiments include ResNet-style and Inception-style networks and squeeze-and-excitation improvements.

- `cnn_classification.ipynb`: model definitions, training procedures and evaluation.

**Stack:** Python, PyTorch, torchvision, Hugging Face Datasets, NumPy and Matplotlib.

**Reproduction:** Install notebook dependencies and fetch the dataset separately. Trained weights are deliberately excluded to keep the portfolio lightweight; training and evaluation may require a GPU.
