# Image Stitching and Geometric Computer Vision

**Topics:** Harris corner detection, homography estimation, RANSAC, SIFT matching and panorama stitching.

This project implements key geometric computer vision algorithms and demonstrates stitching on castle, university and Singapore image pairs.

- `image_stitching.ipynb`: annotated implementation of feature detection, transformation and stitching.
- `examples/`: selected panorama outputs.

**Stack:** Python, NumPy, SciPy, scikit-image, OpenCV, Matplotlib.

**Reproduction:** Run the notebook with the required packages and original input images. The original image dataset is not included in this portfolio version. Some code cells refer to local assignment paths; adjust these before running.
