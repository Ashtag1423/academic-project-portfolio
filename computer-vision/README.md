# Computer Vision & Deep Learning Projects

**Monash University | FIT5221 | 2026**

## Overview

This portfolio showcases my practical experience in computer vision, image processing, deep learning, and transfer learning.

The projects cover image feature detection, image stitching, CNN classification, semantic segmentation, and Vision Transformers.

## Technical Skills

- **Programming:** Python
- **Deep Learning:** PyTorch, CNN, Vision Transformer (ViT)
- **Computer Vision:** Harris Corner Detection, Homography, RANSAC, Image Stitching
- **Model Optimisation:** Data Augmentation, Batch Normalisation, Dropout, Transfer Learning, LoRA
- **Evaluation:** Accuracy, Loss Curves, Mean Intersection over Union (mIoU)

## Project 1 — Image Feature Detection & Stitching

Implemented and evaluated computer vision algorithms for detecting image features and combining overlapping photographs.

**Key Work:**
- Implemented Harris corner detection and compared results with scikit-image.
- Applied homography estimation and RANSAC for geometric alignment.
- Evaluated corner detection and image stitching results on multiple image pairs.

## Project 2 — CNN Image Classification

Conducted experiments on the Tiny ImageNet dataset to investigate the impact of neural network architecture and training strategies.

**Key Work:**
- Developed and evaluated CNN classification models.
- Compared data augmentation, normalisation and dropout techniques.
- Experimented with convolutional kernels, channel sizes, pooling strategies and network architectures.
- Analysed training and testing accuracy to investigate model performance and overfitting.

**Selected Result:** Achieved 29.42% test accuracy using data augmentation, BatchNorm and Dropout in the reported experiment.

## Project 3 — Semantic Segmentation & Vision Transformers

Explored semantic image segmentation and transfer learning using pretrained deep learning models.

**Key Work:**
- Built an FCN segmentation model using an EfficientNet-B0 backbone.
- Investigated residual multi-scale FPN refinement for improved segmentation.
- Evaluated Vision Transformer fine-tuning strategies on the Oxford-IIIT Pet dataset.
- Explored parameter-efficient fine-tuning using LoRA.

**Selected Results:**
- Improved validation mIoU from 0.3222 to 0.5211 using multi-scale refinement.
- Achieved 91.85% test accuracy using partial ViT fine-tuning in the reported experiment.
